Core Architecture

Built for Mission-Critical Deep Learning

Traditional logging records failures after your weights are already corrupt. MLBlackBox protects the training process with continuous flight recording and automated recovery.

⚡

Per-Layer Gradient Profiling

Tracks gradient mean, standard deviation, max/min, and NaN presence across all parameters with less than 1.2% runtime overhead.

🛡️

Sub-Second Checkpoint Rollback

When catastrophic failure strikes, training is instantly halted and rolled back to the last mathematically healthy epoch in under 300ms.

🩺

AI Training Doctor

Heuristic and LLM diagnostics analyze telemetry signatures to isolate culprit layers, explain root causes, and output copy-paste PyTorch code fixes.

🔮

Failure Forecasting

Predictive rate-of-change heuristics warn engineers 2 to 5 epochs before an explosion or stagnation occurs, saving compute hours.

📊

Control Room UI

Full-featured interactive telemetry dashboard built in Streamlit with per-layer heatmaps, loss curves, and checkpoint inspection.

💾

Disk-Safe Checkpoint Ring

Rolling window of compressed checkpoints ensures you never run out of disk space during multi-day model runs.

Developer Quickstart

Integrate in 3 Lines of Code

Drop MLBlackBox into any PyTorch training loop without rewriting your architecture.

Python 3.9+ 
# 1. Import flight recorder
from tracker.checkpoint import CheckpointManager
from training.trainer import Trainer

# 2. Initialize flight recorder manager
flight_recorder = CheckpointManager(model, checkpoint_dir="checkpoints")

# 3. Train with automated fault detection & rollback recovery
trainer = Trainer(model, optimizer, criterion, flight_recorder=flight_recorder)
trainer.train(train_loader, epochs=20)
